# A股量化选股日报系统

A股多因子评分选股系统的 Python 策略代码 + 每日自动报告生成。

## 项目做什么

每日（周一至周五 15:30）自动运行选股策略，扫描成交额前 80 活跃A股，按 4 个因子评分：
- **均线突破**（30%）— MA5 上穿 MA20 金叉
- **量价配合**（30%）— 放量 >1.5 倍 + 上涨 >3%
- **连涨形态**（25%）— 连涨 3~5 天
- **支撑反弹**（15%）— MA60 附近反弹

得分 ≥70 的股票作为信号输出，并持续追踪持仓（超 3 天自动平仓）。

报告输出 3 种风格：社交卡片 / 券商晨报 / 黑客终端，部署在 HuggingFace Spaces 和 ModelScope。

## 目录结构

```
quant/                          ← 项目根目录
├── main.py                     ← 选股策略入口
├── backtest.py                 ← 历史回测
├── data/                       ← 数据获取模块
├── cache/                      ← K 线缓存（不提交）
├── strategies/                 ← 策略模块
├── utils/                      ← 工具（飞书推送等）
├── report-generator/           ← 报告生成模块
│   ├── generate.py             ← cron 调用这个入口
│   └── templates/              ← 3 套 HTML 模板（broker/social/hacker）
└── quant-report/               ← 前端展示仓库（独立 git）
     ├── index.html              ← 报告主页
     ├── reports/YYYY-MM-DD/     ← 每日报告
     └── data/tracking.json      ← 持仓追踪记录
```

## 如何生成报告

```bash
# 手动运行
rm -f ~/.hermes/quant/cache/hist_*.csv
cd ~/.hermes/quant/report-generator
~/.hermes/hermes-agent/venv/bin/python3 generate.py
```

cron 自动调用流程（Job ID: `c391ae790ac4`，周一至周五 15:30）：
1. 清除 K 线缓存
2. `generate.py` → 调用 `main.py` 跑选股策略
3. 判断是否为交易日（非交易日 / 周末直接跳过）
4. 生成 JSON + 3 套 HTML 报告
5. 更新 `quant-report/data/tracking.json` 追踪记录
6. 推送飞书

**删除报告时注意**：需同时删除 `reports/YYYY-MM-DD/` 文件夹和 `data/report-list.json` 中的对应记录，否则页面列表里仍会显示。
